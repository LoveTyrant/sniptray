Using SnipTray

SnipTray lives in the system tray and takes screenshots — a region, a window, or a whole screen — then copies, saves, and lets you drag them straight into other apps.

Getting started

After installing, SnipTray runs in the system tray — the blue square icon near the clock. If you don't see it, click the ^ arrow next to the clock to show hidden icons, and drag SnipTray onto the taskbar to keep it visible.

There are three ways to start a snip:

  • Press the hotkey — Ctrl + Shift + X by default (you can change it).
  • Left-click the tray icon.
  • Right-click the tray icon → Snip now.

SnipTray starts with Windows by default, so it's always ready.

Taking a snip

When you start a snip the screen freezes and dims. Whatever was on screen at that moment is what you capture — even menus and pop-ups that would normally close. A hint bar at the top of each screen reminds you of the options.

A region

Press and drag a rectangle over the area you want, then let go. The size in pixels is shown while you drag.

A window

Move the mouse — the window under the cursor lights up. Click (without dragging) to snip just that window. Over the empty desktop, a click snips the whole screen.

A whole screen

While selecting, press F to snip the entire screen the cursor is on. This works on any monitor.

You can also right-click the tray icon → Snip full screen.

With more than one monitor, Snip full screen from the tray menu captures the screen whose taskbar you opened the menu from — usually your main screen. To snip a different monitor, press the hotkey, move the cursor onto that monitor, and press F.

Delayed snip

Need to capture a menu, a tooltip, or something that only shows while you hover? Right-click the tray icon → Delayed snip and pick 3, 5, or 10 seconds. Open what you want to capture; when the time is up the screen freezes and you select as usual.

To cancel at any point while selecting, press Esc or right-click.

After you snip

Every snip is automatically:

  • Saved as a PNG file in your snips folder (Pictures\Snips unless you change it).
  • Copied to the clipboard, ready to paste.
  • Shown as a small preview in the bottom-right corner.

The preview

The preview appears on your main screen. To have it appear on the screen you snipped instead, turn on Preview on snipped monitor.

Pasting

Press Ctrl + V in any app that accepts images — email, chat, documents, image editors.

If Copy file path as text is on, the file's location is copied too, so terminal apps paste the path instead. If some app pastes a file path where you expected the picture, turn that setting off.

Drag and drop

Drag the preview straight into an email (Outlook app or Outlook on the web), a chat window, a folder, or a document to attach the image file.

Editing a snip

Double-click the preview to open the editor.

ToolKeyUse it to
✏️ PenPDraw freehand
🖍 HighlighterHMark text with a see-through stroke — pick the yellow swatch for a classic highlighter
➚ ArrowAPoint at something
▭ RectangleRBox an area
◯ EllipseECircle an area
▒ Blur regionBHide sensitive details (passwords, names, numbers)
T TextTAdd a label — click where it goes and type. Enter places it, Shift + Enter starts a new line, Esc cancels.
⛶ CropCTrim the snip — drag a box around what to keep. Everything outside darkens while you drag; letting go crops, and you're back on the tool you were using.

Pick a color from the swatches and a line width with the slider. ⤢ Resize scales the whole image — type a size, or use 25 / 50 / 75%; the 🔗 button keeps the proportions.

When you're done, click Save & copy (Ctrl + S). This overwrites the saved file and puts the edited version on the clipboard.

Undo with Ctrl + Z; redo with Ctrl + Y or Ctrl + Shift + Z. Crop and resize can be undone too.

If you close the editor with changes you haven't saved, it asks first: Save & close, Don't save, or Cancel to keep editing.

Recent snips

Lists your last five snips with the time and size, newest first. Clicking one copies it to the clipboard again and brings back its preview, so you can drag it into an app or double-click to edit it.

Settings

Right-click the tray icon → Settings…. Changes save immediately — you'll see Saved ✓.

Hotkey

Click the hotkey box and press the new combination. Letters and numbers need at least one of Ctrl, Alt, Shift, or Win; function keys and PrtSc can be used alone. Press Esc to keep the current one.

A hotkey works everywhere while SnipTray runs, so it takes that combination away from other apps. If you pick one most apps already use — like Ctrl + Z (undo) or Ctrl + S (save) — Settings warns you. Combinations another program has already claimed are refused.

Storage

  • Save snips to — Browse… to pick a folder, or Default to go back to Pictures\Snips.
  • Delete old snips — Never (default), after 7, 30, or 90 days, or Custom… to type any number of days (1–3650). Old snips go to the Recycle Bin, so you can restore them. Only files SnipTray created (named snip_….png) are ever removed — anything else in the folder is left alone.
  • Open folder — shows your snips in File Explorer.

Terminals & Claude Code

Terminal apps such as Claude Code can't receive a pasted picture, but they can open a file from its path. With Copy file path as text on, pressing Ctrl + V in a terminal pastes the snip's path and Claude Code attaches the image.

Dragging the preview into Windows Terminal inserts the path automatically. Warp handles dropped files itself, so they never reach the program inside it — with Terminal drop assist on, SnipTray notices the drop and types the path for you.

Troubleshooting

The hotkey does nothing

Another program may already be using that combination. When this happens at startup, SnipTray opens Settings with an explanation and the tray tooltip says hotkey unavailable. Pick a different hotkey — until then, left-clicking the tray icon still snips.

Pressing the hotkey snips instead of doing something in another app

A global hotkey takes priority over every app. Choose a combination you don't use elsewhere in Settings.

An app pastes a file path instead of the picture

Turn off Copy file path as text in Settings.

Snip full screen captures the wrong monitor

See the multi-monitor note: press the hotkey, move to the monitor you want, and press F.

The icon still looks old after an update

Windows caches program icons. Signing out and back in (or restarting) refreshes them.

SnipTray isn't running

Start it from the Start menu or the desktop shortcut. Starting it a second time while it's already running opens Settings.
